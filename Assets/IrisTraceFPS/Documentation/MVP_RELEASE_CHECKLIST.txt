IRISTRACE FPS — MVP CHECKLIST

IMPORT
[ ] Open in Unity 6.3+ and wait for compilation.
[ ] Console has no IrisTrace compile errors.
[ ] Input System package is installed and enabled.

EDITOR
[ ] Open IrisTrace FPS generator.
[ ] Create, save, duplicate and delete a character configuration.
[ ] Assign and preview a portrait Sprite.
[ ] Create/edit/delete weapon and enemy configurations.
[ ] Confirm delete prompts prevent accidental removal.
[ ] Run Release Audit and Project Validation.

PLAYER
[ ] Generate a NEW hero prefab and test it in Play Mode.
[ ] WASD, mouse look and jump work.
[ ] Holding crouch blocks jumping; cannot stand under a low ceiling.
[ ] Movement and gravity feel responsive.
[ ] Sprint works only when its ability is assigned.
[ ] Fire, ammo, manual reload and automatic reload work.
[ ] Empty-ammo behavior is correct; player is not hit by own weapon.
[ ] Ability HUD shows Q/E slots and cooldowns.
[ ] Assigned Dash, Heal and Sprint abilities work.
[ ] Optional audio clips play; empty audio slots do not break gameplay.

ENEMIES AND OUTPUT
[ ] Training target takes damage and is destroyed at zero health.
[ ] Basic AI detects, follows and attacks the player as configured.
[ ] Test AI with a baked NavMesh; verify fallback behavior separately.
[ ] Generated prefabs/configurations are saved under Assets/IrisTraceFPS_Generated/.
[ ] Regenerating content does not silently erase custom changes.

RELEASE
[ ] Import and test in a clean copy of the project.
[ ] Verify all included models, sounds and other assets have distribution rights.
[ ] Review all warnings in Release Audit; complete manual Play Mode checks.

Passing the automated audit is not proof of release readiness. Do not publish until manual checks are verified in Unity.
