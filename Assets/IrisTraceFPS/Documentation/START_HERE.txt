IRISTRACE FPS — START HERE

1. Open the project in Unity 6.3+.
2. Install/enable Unity Input System if requested.
3. Open Window > IrisTrace FPS > Open Generator.
4. Use Create FPS Hero to configure and generate a player.
5. Use Create Enemy to create a target or basic bot.
6. Run Window > IrisTrace FPS > Release Audit for structure checks.
7. Follow Documentation/MVP_RELEASE_CHECKLIST.txt before sharing the project.

Generated assets are stored in Assets/IrisTraceFPS_Generated/.
The audit checks common setup items only; gameplay still needs manual testing.
